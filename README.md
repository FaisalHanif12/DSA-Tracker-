DSA-Tracker Website
The DSA-Tracker is a website designed for individuals to practice Data Structures and Algorithms (DSA) in a well-organized and comprehensive manner. This platform helps users track their DSA practice and progress across various topics.

Key Features
Topic Partitioning:

The website is divided into multiple DSA topics, such as Arrays, Linked Lists, Trees, Graphs, etc.
Each topic has multiple questions curated for detailed practice.
Question Redirection:

Each question listed under a specific topic redirects to LeetCode.
Users can solve the question on LeetCode after clicking the link.
Marking Questions as Solved:

Once a user solves a question on LeetCode, they can return to the DSA-Tracker and mark the question as solved.
A simple tick/check button is available for marking a question as completed.
Progress Tracking:

The platform tracks the user's progress for each topic.
It shows the ratio of solved to unsolved questions within each topic, helping users stay on top of their practice.
Detailed Practice Overview:

Users can see an overview of their practice, categorized by topics and questions.
It helps them identify which topics need more attention and which ones they have mastered.
User-Friendly Interface:

The interface is clean, intuitive, and easy to navigate, making it perfect for both beginners and advanced users.
Responsive Design:

The website is fully responsive, ensuring it works seamlessly on all devices, whether it’s a desktop, tablet, or mobile.
